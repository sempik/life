# Life — личный менеджер

**Открыть:** https://sempik.github.io/life/

Одно приложение для телефона и компьютера: расписание пар и встреч, задачи и дедлайны,
питание (КБЖУ, вода, вес), полезные и вредные привычки, напоминания. Life сверяет твоё
расписание с сайтами и календарями и сообщает о переносах и отменах пар.

Работает без интернета, ничего не нужно скачивать из магазинов. Данные хранятся на
твоём устройстве и (если включишь) в твоём личном секретном GitHub Gist.

---

## 1. Установка

| Устройство | Как поставить |
|---|---|
| **Android** (Chrome) | открой ссылку → меню ⋮ → **«Установить приложение»** |
| **iPhone / iPad** (Safari) | открой ссылку → «Поделиться» → **«На экран Домой»** (уведомления на iOS работают только так, iOS 16.4+) |
| **Windows / macOS / Linux** (Chrome, Edge) | открой ссылку → значок установки ⊕ справа в адресной строке (или Настройки → О приложении → «Установить») |

После установки Life открывается отдельным окном, как обычная программа, и работает офлайн.

## 2. Что умеет

- **Сегодня** — главный экран: что идёт сейчас и что дальше (с обратным отсчётом),
  лента дня, задачи, привычки, калории и вода, предупреждения о переносах и пересечениях.
- **Расписание** — день / неделя / месяц. Пары по номерам (время звонков настраивается),
  повтор по дням недели, **числитель / знаменатель**, встречи со ссылкой на созвон, тренировки.
  Импорт и экспорт `.ics`. Можно изменить «только эту пару» или всю серию.
- **Задачи** — пиши как думаешь: «сдать лабу пт 18:00 !» → срок пятница 18:00, важная.
  Понимает «завтра», «через неделю», «15 ноября», «в 7 вечера», `#теги`, `!`/`!!`.
  Повторяющиеся задачи, ДЗ, привязанное к паре.
- **Питание** — встроенная база ~190 продуктов, поиск по мировой базе Open Food Facts,
  сканер штрихкода (Android/Chrome), вода, вес с графиком. Норму КБЖУ рассчитает
  по росту, весу, возрасту и цели.
- **Привычки** — полезные (серии 🔥, тепловая карта) и вредные: «бросаю» с живым счётчиком
  чистого времени, сэкономленными деньгами и вехами, или «ограничиваю» с лимитом в день.
  Кнопка «Хочется» записывает, что ты удержался, и даёт совет; «Сорвался» — без осуждения.
- **Источники** — сверка с сайтами: Google / Яндекс / Outlook календари, Moodle и ЭИОС вузов
  (ICS), JSON API или обычная страница с расписанием. Лента изменений: «перенесли»,
  «отменили», «новая пара», расхождения с твоим расписанием.
- **Статистика** — графики за 7 / 30 / 90 дней, экспорт в CSV.
- **Уведомления** — о парах и встречах, дедлайнах, привычках, еде и воде, утренний план
  и вечерние итоги, тихие часы.

## 3. Синхронизация телефона и ПК (бесплатно, через GitHub)

1. Создай токен: https://github.com/settings/tokens/new?scopes=gist&description=Life%20manager
   (галочка **gist**, срок — на свой вкус) → «Generate token» → скопируй.
2. В Life: **Настройки → Синхронизация** → вставь токен → «Подключить».
   Life сам создаст секретный gist с данными.
3. На втором устройстве сделай то же самое с тем же токеном: данные сольются.

**Шифрование (рекомендуется):** там же задай пароль шифрования. Тогда в gist лежит только
зашифрованный файл (AES-256). Пароль нужен на каждом устройстве и боту. Забыл пароль —
облачная копия потеряна (данные на устройствах останутся).

## 4. Бот: уведомления, когда приложение закрыто

Телефон «усыпляет» закрытые веб-приложения, поэтому напоминание от закрытого приложения
может не прийти. Это решает бот — скрипт, который GitHub Actions запускает примерно
каждые 10 минут. Бот:

- присылает **push-уведомления** на телефон и ПК и/или сообщения в **Telegram**;
- проверяет сайты с расписанием и сообщает об изменениях;
- принимает команды в Telegram: `/today`, `/tomorrow`, `/next`, `/water 300`,
  `/eat гречка 200 г`, `/eat шаурма 600 ккал`, `/done зарядка`, `/slip курение`,
  `/crave курение`, `/task сдать лабу завтра 18:00`, `/weight 72.5`, `/stats`.
  Отвечает с задержкой до ~10 минут (так часто запускается бот).

Включение (один раз, нужна синхронизация из п. 3):

1. **Секрет** `LIFE_GIST_TOKEN` = тот же токен:
   https://github.com/sempik/sempik.github.io/settings/secrets/actions/new
2. Если задан пароль шифрования — секрет `LIFE_PASSPHRASE` с этим паролем.
3. **Переменная** `LIFE_BOT` = `on`:
   https://github.com/sempik/sempik.github.io/settings/variables/actions/new
4. Запусти вручную первый раз: вкладка **Actions → life-bot → Run workflow**.
5. Push: в Life **Настройки → Уведомления → «Подписать это устройство»** (на каждом устройстве).
6. Telegram: создай бота у [@BotFather](https://t.me/BotFather), в Life **Настройки → Бот**
   вставь токен бота, напиши своему боту `/start`, нажми «Найти мой chat id» → «Сохранить».

Пошаговая инструкция со статусом бота есть в самом приложении: **Настройки → Бот**.

Особенности GitHub Actions: запуски по расписанию иногда опаздывают на 5–15 минут
(поэтому бот присылает напоминания чуть заранее). Если в репозитории 60 дней не было
коммитов, GitHub приостанавливает расписание: придёт письмо, включается одной кнопкой.
Бот работает и вне GitHub: `LIFE_GIST_TOKEN=... node .github/scripts/life-bot.mjs`
по cron на любом сервере или в Termux.

## 5. Сверка с сайтами — где взять ссылку

| Где расписание | Что вставить в «Источники» |
|---|---|
| Google Календарь | Настройки календаря → «Секретный адрес в формате iCal» |
| Яндекс Календарь | Настройки → «Экспорт» → ссылка на .ics |
| Outlook | Параметры → Календарь → Общие календари → «Опубликовать» → ICS |
| Moodle / ЭИОС вуза | Календарь → «Экспорт календаря» → «Получить адрес календаря» |
| Обычный сайт с расписанием | тип «Веб-страница»: ссылка на страницу и фильтр строк (например, номер группы) |

Некоторые сайты запрещают загрузку прямо из браузера (CORS). Такие источники проверяет бот
(п. 4), либо можно указать CORS-прокси в разделе «Источники».

Совет: включи **Настройки → Синхронизация → «Публиковать календарь»** и подпишись на эту
ссылку в календаре телефона. Тогда пары будут и в родном календаре со штатными напоминаниями.

## 6. Приватность

- Данные хранятся в браузере устройства (IndexedDB). Синхронизация идёт только в твой gist.
- Сторонним сервисам приложение обращается только по твоему действию: поиск продуктов
  (Open Food Facts), проверка добавленных тобой источников, Telegram (если подключишь).
- Бэкап: **Настройки → Данные → «Скачать копию»**.
