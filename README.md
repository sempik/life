# Life — личный менеджер

Расписание пар, задачи, питание, привычки и напоминания в одном веб-приложении (PWA) для телефона и ПК.

**Открыть:** https://sempik.github.io/life/

- Как поставить, синхронизировать и включить бота: [life/README.md](life/README.md)
- Как устроено: [life/ARCHITECTURE.md](life/ARCHITECTURE.md)
- Тесты: `node life/tests/run-all.mjs`

Сайт публикуется автоматически из папки `life/` (workflow `pages`), бот работает через workflow `life-bot`.
